# JavaScript Programming Activities
Coure:CS-1130 Introduction to Computing SEM 1 2026 GERALDE

A simple and interactive website developed using HTML, CSS, and JavaScript. This project contains four programming assignments that demonstrate basic programming concepts through different calculators and simple programs.

## Assignments

1. **Conversion Calculator** – Converts Celsius to Fahrenheit, Fahrenheit to Celsius, meters to feet, and feet to meters.
2. **Income Tax Calculator** – Calculates income tax based on the Philippine income tax brackets.
3. **Factorial, Sum, and Average** – Calculates the factorial, sum, and average of the first N natural numbers using while, do-while, and for loops.
4. **Simple Payroll** – Calculates an employee's gross salary based on their hourly rate and hours worked.

## Technologies Used

- HTML
- CSS
- JavaScript
